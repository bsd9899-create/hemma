# موقع هِمّة — himmah.online

موقع ثابت بالكامل (HTML + CSS، بلا build وبلا اعتماديات). سبب وجوده ليس
التسويق: **App Store Connect يرفض التطبيق بدون رابطين عامّين حيّين** —
سياسة خصوصية، واتفاقية ترخيص/شروط استخدام تعرض شروط الاشتراك المتجدد.
وهذان الرابطان مطلوبان أيضًا داخل شاشة الاشتراك نفسها.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `privacy.html` | سياسة الخصوصية — الرابط المطلوب في App Store Connect |
| `terms.html` | شروط الاستخدام / EULA — يتضمن شروط الاشتراك والتجديد التلقائي |
| `support.html` | صفحة الدعم — رابط "Support URL" المطلوب في App Store Connect |
| `style.css` | التنسيق (ألوان الهوية الرسمية نفسها) |
| `logo.svg` | الشعار الرسمي، منسوخ من `assets/branding/logo.svg` بلا تعديل |

## النشر

أي مستضيف ملفات ثابتة يكفي. المجلد يُرفع كما هو:

**Cloudflare Pages** (مجاني، والنطاق مُدار عندهم غالبًا):
```
Build command:      (اتركه فارغًا)
Build output dir:   website
```

**Netlify**:
```
netlify deploy --dir=website --prod
```

**Vercel**:
```
vercel deploy website --prod
```

ثم اربط النطاق `himmah.online` بالمشروع، وفعّل HTTPS (تلقائي في
الثلاثة). تأكد أن `https://himmah.online/privacy.html` يفتح فعلًا قبل
إرسال التطبيق للمراجعة.

## قبل النشر — مطلوب يدويًا

1. **بريد الدعم**: كل الصفحات تشير إلى `support@himmah.online`. يجب أن
   يعمل هذا البريد فعلًا قبل النشر — Apple تختبره أحيانًا. إن اخترت
   بريدًا آخر، غيّره في الملفات الأربعة.
2. **مراجعة قانونية**: النصوص مكتوبة لتغطي متطلبات Apple المعروفة
   وتصف سلوك التطبيق الفعلي بدقة، لكنها ليست استشارة قانونية.
3. **تحديث التاريخ**: «آخر تحديث» مكتوب يدويًا في `privacy.html`
   و`terms.html` — حدّثه عند أي تعديل جوهري.
4. **الأسعار**: `terms.html` يذكر 19.99 / 99.99 ريال. يجب أن تطابق
   ما تضبطه فعليًا في App Store Connect.
